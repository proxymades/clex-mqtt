# Сообщения об уязвимостях

Проект находится в разработке. Сообщения об уязвимостях принимаются для текущего состояния основной ветки.

Для конфиденциального сообщения используйте [приватную форму GitHub](https://github.com/proxymades/clex-mqtt/security/advisories/new). Укажите версию или коммит, условия воспроизведения, ожидаемое и фактическое поведение и возможное влияние на безопасность. Примеры воспроизведения должны использовать тестовые учётные данные и обезличенные данные.

Проверка сообщений и подготовка исправлений выполняются по мере возможности. Условия предоставления программного обеспечения описаны в [LICENSE](LICENSE).
