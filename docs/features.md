# Возможности

CLEX MQTT – MQTT-брокер со встроенной административной панелью и пользовательскими аккаунтами.

## Обмен сообщениями

| Функция | Описание |
|---|---|
| MQTT 3.1 и 3.1.1 | Подключение, публикация, подписка, отмена подписки, проверка связи и завершение соединения |
| MQTT 5.0 | QoS 0/1/2, свойства сообщений, постоянные сессии, совместные подписки и расширенная аутентификация |
| QoS 0 / 1 / 2 | Доставка с соответствующими подтверждениями и сохранением состояния обмена |
| Постоянные сессии | Восстановление подписок и очередей после переподключения |
| Client ID | Сессия определяется парой «MQTT-учётная запись + Client ID»; для каждой пары ведутся собственные очереди |
| Замена соединения | Повторное подключение с той же учётной записью и Client ID заменяет предыдущее соединение этой пары |
| Retain | Последнее сохранённое сообщение топика; удаление публикацией с пустым payload |
| Last Will | Публикация при обрыве связи с учётом корректного завершения соединения и Will Delay |
| Сроки хранения | Session Expiry, Message Expiry и Will Delay |
| Ограничения MQTT 5 | Topic Alias, Receive Maximum и Maximum Packet Size |
| Свойства MQTT 5 | User Properties, Content Type, Response Topic и Correlation Data; исходные байты payload и порядок User Properties сохраняются |
| Параметры подписок | Subscription Identifier, No Local, Retain As Published и Retain Handling |
| Совместные подписки | Распределение сообщений между участниками группы; очереди и порядок выбора участников сохраняются в хранилище |

В совместных подписках назначенные доставки QoS 1/2 закрепляются за выбранной сессией. Повторная доставка назначенного сообщения выполняется в рамках этой же сессии.

## Подключение и доступ

| Функция | Описание |
|---|---|
| TCP и TLS | Подключение по IPv4/IPv6, TLS с серверным сертификатом |
| WebSocket и WSS | MQTT поверх WebSocket; WSS через HTTPS-прокси |
| MQTT-логин и пароль | Проверка учётных данных, хранение паролей с Argon2 |
| SCRAM-SHA-256 | MQTT 5: обмен CONNECT/AUTH/CONNACK, проверка сервера клиентом и повторная аутентификация в открытом соединении |
| Клиентские сертификаты | mTLS, проверка CA, срока действия и clientAuth, привязка SHA-256 отпечатка к MQTT-учётной записи и индивидуальный отзыв |
| Права доступа | Разрешения на публикацию и подписку для заданных фильтров топиков |
| Группы и шаблоны | Общие правила для нескольких MQTT-учётных записей, шаблоны ролей и приоритет явных запретов |
| Проверка доступа | Итоговое решение ACL с указанием применённых правил |

Публикация и подписка требуют соответствующих разрешений ACL. Активные соединения используют проверки поколения сессии, состояния учётной записи и клиентского сертификата.

## Панели управления

| Функция | Описание |
|---|---|
| Административная панель | Обзор брокера, MQTT-учётные записи, группы, подключения, сообщения, Retain и журнал действий |
| Пользовательские аккаунты | Регистрация по настройке сервера, собственные MQTT-учётные записи, подключения, сообщения и Retain |
| Изоляция аккаунтов | Собственное пространство топиков и индивидуальные квоты |
| Управление аккаунтами | Блокировка, изменение ограничений и сброс пароля кабинета администратором |
| Защита входа в веб-панели | Ограничение попыток по IP и настройка доверенных прокси |
| Журнал действий | Успешные входы, отказы, ограничения и изменения настроек; фильтры и постраничный просмотр |
| Параметры сервера | Просмотр слушателей и сертификатов в панели; настройка через переменные окружения |
| Мосты между брокерами | Управление MQTT 5 подключениями по TCP/TLS, импортом и экспортом сообщений с заменой префиксов |

Мосты передают сообщения с QoS 1, сохраняют Retain и свойства MQTT 5, используют долговечные очереди и восстанавливают связь после разрыва соединения.

## Наблюдение и диагностика

| Функция | Описание |
|---|---|
| Поток сообщений | Последние принятые публикации в ограниченном буфере; фильтры по Client ID, MQTT-логину и топику |
| Просмотр содержимого | Текст, бинарный payload в Base64, копирование, поиск и пауза просмотра |
| Prometheus | Защищённый OpenMetrics endpoint: подключения, публикации, очереди, мосты и состояние хранилища |
| Grafana | Панели брокера, ресурсов сервера и резервных копий |
| Диагностика публикации | Источник, маршрутизация, ожидание хранилища, постановка в очередь, отправка и подтверждения получателя |
| Нагрузочные измерения | Изолированный брокер и MQTT.js-клиенты, QoS 0/1/2, проверка доставок, задержек, CPU и памяти |

Диагностический сеанс длится до 300 секунд и хранит до 100 публикаций, 128 событий на публикацию и 8 МиБ метаданных.

## Проверка совместимости

Независимые проверки формируют MQTT-пакеты и проверяют обмен через TCP с отдельной тестовой БД. В сценарии входят:

- подтверждения QoS, Receive Maximum и обработка PING во время ожидания подтверждений;
- создание, повторное использование и переназначение Topic Alias;
- граничные размеры пакетов и проверка свойств MQTT 5;
- совместные подписки, переподключение участников, очереди и проверка ACL;
- SCRAM-SHA-256 по RFC 7677, подпись сервера, повторная аутентификация и отзыв доступа;
- восстановление сессий и обменов QoS после перезапуска процесса.

Начальная выдача Retain выполняется для обычных подписок. Участники совместных подписок получают сохранённые сообщения при дальнейших публикациях.

Протокольная основа – [MQTT 5.0 OASIS Standard](https://docs.oasis-open.org/mqtt/mqtt/v5.0/os/mqtt-v5.0-os.html). Команды проверок описаны в [README](../README.md#проверки).
